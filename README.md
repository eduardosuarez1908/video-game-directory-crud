# Sistema de Gestión de Directorio de Videojuegos
Proyecto académico desarrollado como parte de mi formación en Desarrollo de Software y Ciberseguridad en el Instituto Superior Tecnológico Cordillera.

## Descripción
Sistema básico para gestionar un directorio de videojuegos, permitiendo ingresar, buscar, modificar y eliminar registros.

## Funcionalidades
- Registro de videojuegos.
- Búsqueda de datos.
- Modificación de registros.
- Eliminación de registros.
- Organización de información.

## Habilidades aplicadas
- Lógica de programación.
- Manejo de datos.
- Estructuras condicionales.
- Organización de información.
- Resolución de problemas.

### Estado del proyecto
Proyecto académico en desarrollo y mejora continua.
