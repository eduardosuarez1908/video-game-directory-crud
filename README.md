<h1 align="center">
Sistema de Gestión de Directorio de Videojuegos
</h1>

Proyecto académico desarrollado como parte de mi formación en Desarrollo de Software y Ciberseguridad en el Instituto Superior Tecnológico Cordillera.

## Descripción
Este sistema permite gestionar un directorio básico de videojuegos mediante operaciones CRUD: registrar, mostrar, buscar, modificar y eliminar registros.
El proyecto funciona desde consola y está orientado a practicar lógica de programación, organización de información y manejo de estructuras de datos.

## Funcionalidades
- Registro de videojuegos.
- Búsqueda de datos.
- Modificación de registros.
- Eliminación de registros.
- Organización de información.

## Tecnologías utilizadas
- Python
- Programación estructurada
- Funciones
- Listas y diccionarios
- Entrada y salida de datos por consola

## Habilidades aplicadas
- Lógica de programación.
- Organización de información.
- Resolución de problemas.
- Manejo de estructuras de datos.
- Validación básica de opciones.
- Diseño de menú interactivo.
- Documentación de proyecto en GitHub.

## Ejemplo de uso
El sistema muestra un menú con opciones para registrar, consultar, buscar, modificar y eliminar videojuegos del directorio.
